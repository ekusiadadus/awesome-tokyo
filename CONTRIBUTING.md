# Contributing

Help someone take their first step into Tokyo's developer and founder community.

Open an issue or pull request with:

- The name and official URL.
- A location within Tokyo Metropolis, or a Tokyo-based community with Tokyo events.
- Who it is useful for and what makes it worth including.
- Language information supported by an organizer's page or clearly dated first-hand experience.
- Entry requirements: RSVP, application, membership, booking, or walk-in.
- The date checked and any uncertainty about price, access, or laptop use.

An English website alone does not prove English-speaking staff or an English-language event. A public event does not make the host's workspace public. A cafe is not a guaranteed networking venue. Keep these distinctions clear.

For communities that also run events elsewhere, link only Tokyo events as recommendations. Exclude venues outside Tokyo Metropolis, affiliate links, unsupported rankings, and promotional copy. Disclose an affiliation with a suggested venue.

Do not copy descriptions from directories. Write a short original explanation and link the primary source. For closures or changed access policies, supply a current official notice; remove or mark the outdated recommendation promptly.

Maintainers should review access rules and event links monthly, and lodging/cafe entries quarterly. These are maintenance targets, not a claim that an automated review is running.
